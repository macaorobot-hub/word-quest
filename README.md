# Word Quest · 職業大冒險

41 個英文生字及詞組：29 個重點生字，12 個認讀生字。保留原版英式拼字、中文意思及拼字分段提示（分段是記憶輔助，不是國際音標）。

## 遊玩

開啟 https://macaorobot-hub.github.io/word-quest/ 。iPad Safari 可選「分享 → 加入主畫面」。

看圖選字、觸屏拼字、聽音辨字、生字學習室及錯題重練。錯題與星星只存於瀏覽器本機；清除網站資料會刪除紀錄。沒有登入、追蹤器、個人資料或課本照片。

首次成功載入後，可離線使用已快取的遊戲。語音使用裝置的英式英文文字轉語音，聲音及離線發音支援取決於系統；須點擊播放按鈕。

## 開發

純 HTML/CSS/JavaScript，無外部相依套件。用任何靜態網頁伺服器開啟。GitHub Pages 從 main 根目錄發佈。

## 寶可夢拼字挑戰

每輪從 29 個重點生字隨機抽取 2 個不重複詞語。全部拼對後，隨機解鎖一隻尚未收藏的寶可夢（共 1,025 隻，包含 71 隻傳說、23 隻幻之寶可夢）。答錯可重試、可用音節提示；中途離開不會獲得獎勵。圖鑑可重看圖片、繁體中文及英文名稱、分類、屬性、身高體重、特性、進化關係和六項種族值。

收藏以 `word-quest-pokemon-v1` 儲存在同一瀏覽器；正常使用不重複解鎖，收齊後不再發獎。支援 Web Locks 的瀏覽器亦會序列化不同分頁的解鎖。收藏不跨裝置同步，清除網站資料會清除收藏。資料無法儲存時會提示，不會默默發出不能保存的獎勵。

寶可夢資料：PokéAPI 的 https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv （2026-11-27 取得）。圖片：https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork 。圖片在本網站提供，瀏覽過的圖片可離線快取；未瀏覽的圖片仍需網絡。寶可夢角色及圖像屬其各自權利人所有，此為非官方學習作品。沒有把收藏或學習紀錄傳送到 PokéAPI。

## 擴充圖鑑

收錄 PokéAPI 資料庫的 1,025 個物種，各使用其預設形態，形態變化並不當作另一隻收藏。既有收藏鍵與物種編號保持不變，因此舊收藏會保留。
每第 3 次解鎖，若尚有未收藏的傳說或幻之寶可夢，優先從該組抽取；其他次數仍可能抽到稀有夥伴。稀有組收齊後，繼續從其餘未收藏物種抽取。
詳細資料包含獨立撰寫的傳說／幻之寶可夢故事摘要、依結構化資料產生的物種介紹、初登場世代、體色、特性效果、進化關係、六項能力的用途與屬性防禦倍率。所有 94 隻傳說／幻之寶可夢均有專屬摘要。屬性倍率不計特性、道具、太晶化或招式的特殊效果；資料以預設形態及現代屬性表為準。圖鑑可按分類篩選，也可搜尋已收藏的中文名、英文名與編號。
故事事實依 PokéAPI 的 pokemon_species_flavor_text 資料整理，特性效果使用 ability_flavor_text 的繁體中文資料。圖片按需載入，不會預先下載全部 1,025 張。
